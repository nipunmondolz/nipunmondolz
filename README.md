# Nipun Mondol

**I build things that have to work when nobody is watching.**

Encrypted storage that has to survive a lost pendrive. A multimodal pipeline that has to admit when it is uncertain. A notes app that has to keep your work when the tab closes. I care about the part after "it runs on my machine" — the failure modes, the edge cases, and the evidence that something actually did what it claims.

Currently working across machine learning, Flutter, and the web.

### Selected work

**[smartedustream](https://github.com/nipunmondolz/smartedustream)** &nbsp;·&nbsp; `Python` `PyTorch` `ASR` `OCR`
A multimodal pipeline that estimates how difficult an educational video is and shows the evidence behind every decision. Fourteen instrumented stages, traceable evidence routing, and a review queue for the cases it cannot settle alone. Five silent pipeline failures found and fixed — one of them was quietly destroying 40% of the dataset without raising a single error.

**[Sindook](https://github.com/nipunmondolz/Sindook)** &nbsp;·&nbsp; `Flutter` `Dart` `Cryptography`
An encrypted file vault for ordinary USB drives. AES-256-GCM with per-file keys, Argon2id key derivation, streaming encryption so multi-gigabyte videos never blow up memory, and encrypted filenames so the manifest gives nothing away. The same vault opens on Windows and Android. 28 tests.

**[fitbalance](https://github.com/nipunmondolz/fitbalance)** &nbsp;·&nbsp; `Flutter` `Dart` `Offline-first`
An offline health and lifestyle app with a bilingual Bangla/English interface — calorie targets, daily logs, habits, reminders and progress tracking, with automated tests and a privacy reset that actually clears everything.

**[memora](https://github.com/nipunmondolz/memora)** &nbsp;·&nbsp; `JavaScript` `IndexedDB`
A note-taking workspace built with no framework at all. Rich text, code blocks, LaTeX equations, a freehand drawing canvas, sticky notes, image upload and a Pomodoro timer — persisted locally in IndexedDB.
